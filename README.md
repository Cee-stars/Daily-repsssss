# DAILY REPS

英語トレーニングの記録アプリ。1ファイル（`index.html`）で動きます。

## 使い方は2通り

**1. これまで通り（端末内に保存）**
`index.html` をブラウザで開く／ホーム画面に追加する。記録はその端末の中だけに残ります。オフラインでも動きます。

**2. Artifact として開く（自動同期）**
Claude の Artifact として公開すると、記録が `data/state.json` に保存され、
iPhone・iPad・Mac のどこで開いても同じ記録が出ます。
ヘッダーに「同期済み」のチップが出ていれば同期が効いています（タップで今すぐ同期）。

同期のしくみ:

- チェックすると、まず端末内に保存 → 約2秒後にまとめて書き出す（連打しても1回）
- 読み込みは、開いたとき・アプリに戻ったとき・1分ごと
- 端末どうしで食い違ったら **日付ごとに新しいほうを採用**（同時刻ならチェックを合体）
- タスク一覧は最後に編集したほうを採用
- 同期が使えない場所では自動的に端末内保存だけに切り替わります（記録は消えません）

## Artifact 用ページを作り直す

`index.html` を直したら、次を実行して出てきたファイルを公開します。

```sh
python3 tools/build-artifact.py
# → build/daily-reps.artifact.html
```

Artifact は `<html>`／`<head>`／`<body>` を自前で付けるため、その外枠だけを外したページを作ります。
アプリのコードは `index.html` の1本のままです。
