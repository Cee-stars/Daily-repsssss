★ を押すとコア習慣になります。コア習慣を全部やった日は連続日数が続きます。

自動同期

Cloudflare に置くと、この端末に GitHub のトークンを持たせずに済みます。鍵はこのアプリ専用で、ほかには何も触れません。
Cloudflare の Worker → 設定 → 変数とシークレットに、シークレットとして入れた REPS_KEY と同じものです。
置き場と同じ場所からアプリを開いているなら、空で構いません。 ほかの場所から開くときだけ https://<名前>.workers.dev/api/state のように入れます。
GitHub Gist で同期する（前からの方法）
瞬間英作文・My Dictionary と同じ Gist に、このアプリのぶんを daily-reps.json として置きます。ほかのアプリのファイルには触りません。
トークンと Gist ID がそのまま入ります。手で打ち込む必要はありません。
作成ページ で scope の gist にチェックを入れて作ります。 classic（ghp_ で始まるもの）が必要です。 fine-grained（github_pat_）は Gist に対応していません。
空のままで構いません。トークンだけで「同期を始める」を押すと、 瞬間英作文と同じ Gist を自分で見つけます（無ければ作ります）。

モンスターを選ぶ

タスクを1つ終えるたび、そのカードがその場で握りつぶされて岩の玉になり、隕石として飛んでいってこいつに当たります。その日のぶんを全部終えると倒せます。 選んだモンスターはこの端末だけの見せ方です。記録には入りません。
